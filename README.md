# Demo builds

Trial and demonstration builds of the software in the Johnson Script Designs
portfolio. The binaries live under the [`demo` release](../../releases/tag/demo)
so each one has a stable, direct download link.

## Marina Reservation System — desktop trial

The thirty-day trial of the booking desk for Windows and Linux. It runs against
its own local SQLite store and syncs to MySQL when you point it at a server.

| Build | File |
| --- | --- |
| Windows 10+ (x64) installer | `marina-reservation-system-5.4.3-windows-setup.exe` |
| Linux (amd64) Debian package | `marina-reservation-system-5.4.3-linux-amd64.deb` |
| Linux (x86_64) tarball | `marina-reservation-system-5.4.3-linux-x86_64.tar.gz` |

The booking website is not part of the trial; it ships with the Deluxe plan.

## Verifying a download

`SHA256SUMS.txt` in the release lists the checksum of every file.
